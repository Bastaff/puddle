# Changelog

## 0.0.7

- **A teammate's page shows how they work again:** what the agent worked on, plan limits, conversation size, task
  size, recent conversations, code changes, prompt by prompt and tokens per day are back, every number from before,
  drawn as tiles in the new style. Point at or tap any bar, square or dot for its detail.
- **It fits any window:** from a narrow strip at the side of the screen to a wide display, and with larger text.
- **Plan limits fill up:** each limit is a shape that fills as it's used, blue, then amber from 80% and red from 95%.
- **The website's front page shows what Puddle looks like again:** the team, a teammate up close and Me, from the
  demo.
- **Puddle runs on the newest version of the framework the app is built with (Tauri 2.12).**
